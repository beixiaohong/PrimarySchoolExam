## 一、系统上下文

单仓、单进程、同源托管：一个 FastAPI 应用同时提供 API 与两套前端静态资源。

```
                 浏览器
   学生端 SPA          管理后台 SPA
  (web/dist)          (admin/dist)
        │                   │
        └──────┬────────────┘
               │ HTTP/HTTPS（同源，无 CORS）
        ┌──────▼───────────────────────────────┐
        │  FastAPI 应用（uvicorn / systemd exam-app）
        │  ┌─────────────────────────────────┐ │
        │  │ 依赖层：require_self / quiet_hours│ │
        │  ├─────────────────────────────────┤ │
        │  │ 路由层 routers/（36 文件 + 7 包） │ │
        │  ├─────────────────────────────────┤ │
        │  │ 服务层 services/（24 文件 + 2 包）│ │
        │  ├─────────────────────────────────┤ │
        │  │ 数据层 models/ + database.py     │ │
        │  └─────────────────────────────────┘ │
        └───────┬──────────────┬───────────────┘
                │              │
          MySQL 8 主库    外部服务（AI / SMTP / 采集站点 / TTS）
```

**要点**

- 前后端**同源部署**（后端托管 `web/dist` 与 `admin/dist`），因此**未启用 CORS**；若分离部署需自行加中间件。
- 后端为**单体应用**：模块间以 Python import 直接调用，无 RPC/消息队列。
- 批处理方法论：定时任务**代码内置**（`tools/scheduler.py` 的 `JOBS`），随 git 提交，配合线上 crontab 每 15 分钟拉起。

## 二、分层架构

| 层 | 目录 | 职责 | 约束 |
|---|---|---|---|
| 入口 | `run.py` / `app/main.py` | 建应用、注册路由、挂载静态资源、lifespan 启动流程 | 路由注册集中在此，禁止在业务文件内 `include_router` 到 app |
| 横切依赖 | `app/routers/auth.py`、`quiet_hours.py` | 登录校验 + 严格账号绑定；夜间免打扰 | 以 router 级 `dependencies` 挂载，不在每个端点重复写 |
| 路由层 | `app/routers/` | 参数校验、鉴权、调用服务层、组装响应 | **不放业务逻辑**；大模块拆同名子包（admin/study/tasks/exam/classical/rewards/vocab） |
| 服务层 | `app/services/` | 业务规则、外部调用、算法（出题/判分/渲染/采集） | 可被多个路由复用；外部 IO 集中在 `ai.py` / `mailer.py` / `paper_crawler.py` |
| 数据层 | `app/models/` + `app/database.py` | ORM 模型、引擎与会话 | 模型只定义结构与关系 |
| 校验层 | `app/schemas/` | Pydantic 请求/响应模型 | 仅 7 个文件，多数接口仍用 `Query`/`Body` 直参 |
| 迁移层 | `app/migrations/` | 版本化 DDL 与种子 | 必须**幂等**；启动时自动执行 |

### 分层调用示例（每日任务）

```
GET /api/tasks/daily?user_id=U
   │  router 级依赖：require_self（401 未登录 / 403 越权）
   ▼
routers/tasks/daily.py         # 取参数、取当前用户
   ▼
routers/tasks/service.py       # _ensure_today_rows() 生成/补齐当日任务行
   ├── progress.py             # 各任务完成进度计算
   ├── constants.py            # 学科/任务类型/配额常量
   └── models/daily_task.py    # ORM 读写
   ▼
返回 _build_payload() 组装的 JSON
```

## 三、请求生命周期

1. **uWSGI/uvicorn 接收** → `app/main.py` 的 FastAPI 实例。
2. **router 级依赖**（按挂载顺序执行）：
   - `require_self`：校验 `Authorization` 头 token → 查 `users.token` 与有效期 → 强制请求里的 `user_id` 等于登录账号，否则 403。
   - `check_quiet_hours`（仅 9 个动作类前缀）：22:30–次日 07:00 拒绝写操作，返回含「夜间休息」的 403。
3. **端点函数**：`Depends(get_db)` 注入会话；参数由 FastAPI 校验。
4. **服务层**：执行业务规则。**若需调用外部服务（AI/HTTP/SMTP），必须先归还 DB 会话**（见 §6.1 铁律）。
5. **响应**：Pydantic/dict → JSON。`finally: db.close()` 归还连接。
6. **日志**：`log/YYYY-MM-DD.log`（按天滚动，超 20MB 拆 `.partN`）。

> 事务说明：`get_db` **只 close 不 commit**。端点内需显式 `db.commit()`；未 commit 的写入在连接归还时回滚。
> 这解释了一类典型现象：「接口报错但数据已保存」——只要前段逻辑已 commit，后续抛错不影响已落库部分。

## 五、关键设计决策

| # | 决策 | 选择 | 理由与影响 |
|:--:|---|---|---|
| 1 | 数据库 | **MySQL-only** | 已移除 SQLite。连接串 `mysql+pymysql://...?charset=utf8mb4`；`DB_DRIVER` 强制回退 mysql。跨 dialect 兼容仅保留 `_ensure_column` 与 `_longtext()` 两处适配 |
| 2 | 迁移 | **自建版本化脚本** | 未引入 Alembic。001–025 是历史 SQLite 脚本，MySQL 下预置「已执行」、由 `create_all` 建表；026+ 幂等执行，状态记 `schema_migrations`。代价：需手写幂等（inspector / try-except） |
| 3 | 鉴权 | **DB 会话 Token + 严格账号绑定** | 非 JWT。`require_self` 强制 `user_id == 登录账号`，杜绝越权查改；家长模式是同一账号 + 家长密码，不受影响 |
| 4 | 前端托管 | **同源 + 双 dist** | 免 CORS；代价是前端改动**必须重建 dist** 才生效（沙箱常因未重建而「改了没变化」） |
| 5 | AI 接入 | **单入口 `services/ai.py`** | 多供应商 fallback（智谱 → Relay → DeepSeek），按 token 扣钻石。所有路由统一走此入口，便于限流与成本管控 |
| 6 | 连接池 | **10 + 30 / timeout 15** | 曾因 AI 长请求占连接导致 QueuePool 耗尽全站卡死；扩容只是缓解，根本约束见 §6.1 |
| 7 | 任务系统 | **强制/可选双轨 + 家长可整体替换** | 强制任务按学科配置 code 列表整体替换默认值（未配置才回退默认）；家长自定义任务 `custom:N` 生命周期归 `/custom-task` 管理 |
| 8 | 外部模块 | **命名空间隔离** | IM 与账本由外部项目迁移而来，表名统一 `db_` 前缀，路由独立文件，不污染教学域 |
| 9 | 定时任务 | **代码内置 `tools/scheduler.py`** | 任务声明在 `JOBS`（once/daily/weekly + 时刻 + 次数上限），状态记 `tools/.scheduler_state.json`，幂等可重触发；不依赖任何外部自动化平台 |
| 10 | 大模块拆分 | **子包化** | `routers/` 下 7 个子包、`services/` 下 2 个子包（`init_data/`、`math_generator/`）。规则：`common.py` 放公共依赖，按功能切薄路由文件 |

## 六、硬性约束与反模式

### 6.1 🚫 严禁「持 DB 连接等外部阻塞调用」（曾致全站卡死）

- **根因**：AI 类接口在 `get_db` 会话期间调用外部 AI/HTTP/SMTP/SMS，长时间占用连接 → QueuePool 耗尽 → 全站 `TimeoutError` 卡死。
- **规则**：任何路由/服务里**绝不允许**持有 `Session`/`db` 时发起外部阻塞调用（requests/urllib/httpx/aiohttp/smtplib/AI SDK 等）。
- **正确模式**：仅 DB 读写时持连；外部调用前 `db.close()`，或用 `with SessionLocal() as s:` 包住 DB 段。AI 端点采用「分段短会话」：读写 → 关 → 调 AI → 再开短会话落库。
- **已修复清单（勿回退）**：`ai.py` `ai_quiz.py` `assistant.py` `exam.py` `grading.py` `qa.py` `reading.py` `search.py` `study.py` `judge.py` `reading_service.py` `review_service.py` `weather.py` `auth.py(_send_code)`。

### 6.2 其它红线

| 红线 | 说明 |
|---|---|
| 前端改动必须重建 dist | `cd web && npm run build`（管理端 `cd admin && npm run build`），否则后端仍托管旧产物 |
| 迁移脚本必须幂等 | 启动即执行，重跑不能报错、不能重复插种子；跨 dialect 加列用 `_ensure_column`，MySQL 的 TEXT/MEDIUMTEXT **不允许 DEFAULT** |
| 不得绕过 `require_self` | 新接口统一挂 `user_auth_deps`；只读接口也要防越权 |
| 不得直连克隆库写线上数据 | `192.168.2.158` 是线上库的本地克隆；写线上内容必须在线上服务器执行（同步用 `tools/sync_prod_to_local.py`） |
| 敏感配置不入库 | `.env`、`.env.prod`、`qb_versions/`、`data/`、`log/`、`output/`、`temp/` 均在 `.gitignore` |
| 定时任务加进 `JOBS` | 采集/汇总/定时类任务写进 `tools/scheduler.py`，不要另起外部自动化 |

## 七、横切机制

| 机制 | 实现 | 说明 |
|---|---|---|
| 鉴权 | `routers/auth.py: require_self` / `_require_admin` | token 存 `users.token`，TTL 由 `USER_TOKEN_TTL_HOURS` 控制（默认 12 小时） |
| 夜间免打扰 | `routers/quiet_hours.py: check_quiet_hours` | 22:30–次日 07:00 拦截 9 个动作类前缀；只读接口放行 |
| 日志 | `app/logging_setup.py` | `DailySizeRotatingHandler`：按天 + 超 20MB 拆 part，保留 30 天，控制台与文件双写 |
| 迁移 | `app/migrations/runner.py` | 启动时按编号执行未应用版本；结果写 `schema_migrations` |
| 种子数据 | `services/init_data/` | 启动时 `ensure_initial_data()` 幂等导入（词库/古诗文/题型/语法/管理员） |
| 调度 | `tools/scheduler.py` | `JOBS` 声明 + 状态文件，crontab 每 15 分钟拉起 |
| 采集暂存 | `database.py: STAGING_DB_URL` | 主库不可用时先落本地 SQLite，再用 `qb_release.py` 抽取成版本脚本传线上 apply |
| 文档开关 | `config.py: ENABLE_DOCS` | 生产默认关闭 Swagger / ReDoc / OpenAPI |

## 九、扩展指南（新增一个业务模块的标准姿势）

1. **模型**：`app/models/<x>.py` 定义类 → 在 `app/models/__init__.py` 导出。
2. **迁移**：新增 `app/migrations/versions/0NN_<name>.py`，用 inspector/try-except 保证幂等。
3. **服务**：`app/services/<x>.py` 写业务规则（外部 IO 单独封装）。
4. **路由**：小模块 `app/routers/<x>.py`；预计超过 300 行则建子包
   （`__init__.py` 建 router + `common.py` 放公共依赖 + 若干薄路由文件）。
5. **注册**：`app/main.py` 的 `from .routers import ...` 与 `include_router(...)`（挂 `user_auth_deps`，动作类再加 `check_quiet_hours`）。
6. **前端**：`web/src/views/XxxView.vue` + `router/index.js` 登记 + `api/http.js` 加方法。
7. **测试**：`tests/test_<x>.py`，覆盖正常/越权/边界三类。
8. **文档**：更新 `docs/项目说明书.md` 模块表与本文件 §四 数据域表。
