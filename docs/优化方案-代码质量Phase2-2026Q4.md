## 一、立即可做（高确定性 · 低风险 · 可验证）

### A. 补齐 5 个新功能的集成测试

- **动作**：新增 `tests/test_novel_community.py`（书签+评论+榜单）、`tests/test_study_calendar.py`、`tests/test_parent_report.py`，沿用 `test_novel.py` 的 `TestClient + admin_headers` 风格 + 真实 MySQL 测试库。
- **验证**：`pytest tests/test_novel_community.py tests/test_study_calendar.py tests/test_parent_report.py -q` 全绿；全量回归仍 RC=0。
- **风险**：纯增量，零生产影响。

### B. 删除 `temp/` 草稿副本目录
- **依据**：`temp/` 103 文件，**未被 git 跟踪**（删之不影响版本库）；app/ 中仅以注释形式出现（`适配自 temp/wulala/...`），无任何 `import temp`/`import wulala` 真实依赖；内容为已被正式 im/ledger 代码取代的草稿。属纯噪音。
- **动作**：`shutil.rmtree('temp')`。**不删** `.pc_cache`/`.paper_cache`/`qb_versions`/`output`（属缓存/产物，已被 .gitignore 忽略，留作运行产物）。
- **验证**：删除后 `pytest` 全量仍 RC=0；grep `wulala` 仅剩注释（无害）。
- **风险**：零（非版本库、非被引用）。

### C. 迁移约定护栏（防 078 类坑复发）
- **依据**：078 误用 alembic 写法导致启动期迁移导入失败、全站测试大面积 ERROR（已修）。项目迁移是自定义 runner（`upgrade(db)` + 原生 SQL + `information_schema` 幂等检测），**未安装 alembic**。此类错误只在 `import app` 时才暴露，CI 前不可见。
- **动作**：新增 `tests/test_migrations_lint.py`：
  1. 扫描 `app/migrations/versions/*.py`，禁止出现 `from alembic` / `import alembic`；
  2. 每个迁移必须定义 `upgrade(db)` 函数且签名含 `db` 参数。
- **验证**：该测试本身全绿；人为注入 alembic 引用会被立刻拦截。
- **风险**：纯增量，零生产影响。

### D. 上帝文件拆分（前端 appOptions.js / App.vue，后端 im.py / ledger.py）

> **执行结论（2026-09-23）**：现状复核发现 im/ledger 已有 `services/` 分层、appOptions.js 已抽 parent/ledger/im.js，**并非原始巨石**。故改为"聚焦低风险纯函数提取 + 补回归测试"，而非盲目拆巨石。

- **后端 ledger.py（已完成）**：抽离 3 个纯函数（`_adjust_balance`/`_advance_next_run`/`generate_financial_report`，177 行）至 `app/domains/frozen/services/ledger_calc.py`，`ledger.py` 改为 import 引用、函数名与行为不变。配套 `tests/test_ledger_api.py`（9 用例）锁定余额变更逻辑。全量回归 RC=0。commit 7999d4e / e646c83。
- **后端 im.py（保留不拆）**：`_guard_text` 是 router 层敏感词+审计薄封装（被群名/群简介/红包祝福/消息/公告 5 处调用），属 router 职责，拆到 services 反而割裂审计上下文；`ConnectionManager` 为模块级 WS 单例，绝不动。剩余端点均为结构化 CRUD，抽子 router 收益低于风险。
- **前端 appOptions.js（已全部拆完 · 9 个独立 logic 文件）**：原 3059 行，先已抽 `parent/ledger/im.js`；Tier2 继续抽 `auth`(登录/注册/重置/绑定)/`focus`(专注钟)/`dict`(听写磨耳朵)/`cards`(知识卡图鉴·抽卡·徽章)/`pet`(宠物家园·成长树)/`recite`(单词背诵·古文默写) 共 9 个文件。每个均导出三字典（`xxxData()`/`xxxComputed`/`xxxMethods`）+ `appOptions.js` 用展开运算符合并，行为零改动。抽取用 **brace-aware 机械脚本**逐个方法精确提取、跳过共享方法（`wordSpeak`/`textSpeak`/`loadDiamonds`/`loadTaskConfirms` 留主文件），逐块 `vite build` 验证 + 最终整体 build（**121 modules、0 error**）。**最终量化**：`appOptions.js` 降至 2478 行（净减 ~580 行）；9 文件合计 ~2848 行。剩余主文件为通用生命周期（`login`/`logout`/`refreshAll` 调度/年级科目/天气）+ quiz/错题本/复习队列等**跨视图协调层（基础设施）**，拆分收益低于回归风险，**建议停**。后端全量 `pytest` 回归 **RC=0、无失败**（仅 `utcnow()`/`Subquery` 无害弃用告警）。各 commit：auth 94f6041 / focus 1e37692 / dict 0a91bb6 / cards 8758d47 / pet d12699c / recite e103f91。
