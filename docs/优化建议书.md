  - 同时在 `.env.example` 补 `QUIZ_SECRET` 说明；存量链接签名兼容（默认值与旧值一致，无需重签）。

### P1-3 死代码与冗余依赖清理

  - `app/tools/wulal.py`：PDF→PNG 工具，**全仓无任何 `import wulal` / `pdf_to_images` 调用**（Grep 核实），置于 `app/` 包内却未接线。

## P2 · 中优先级（有空就做，不紧急）

### P2-1 路由前缀一致性（已核对：无需改动）
- **复核结论**：审计时误判 `diamond.router` 挂在 `/api` 即接口为 `/api/balance`。实际 `app/routers/diamond.py:17` 的 `APIRouter(prefix="/diamond")`，叠加 `app/main.py` 的 `prefix="/api"`，真实接口为 `/api/diamond/balance`、`/api/diamond/ledger`、`/api/diamond/recharge/config`、`/api/diamond/adjust`、`/api/diamond/grant-all`。
- **前端已对齐**：`web/src/stores/wallet.js:32` 与 `web/src/logic/appOptions.js:665/674` 均调用 `/api/diamond/*`，`admin/` 走 `/api/admin/*`，无遗留旧路径。OpenAPI 校验确认无 `/api/diamond/diamond/`（双前缀）等异常。
- **处置**：**无需改动**。审计 P2-1 前提有误，特此更正——命名实际已一致。

### P2-2 `.gitignore` 误伤风险消除
- **证据**：`.gitignore` 含 `app/models/__init__.py`。`git check-ignore` 当前对该文件**无输出**、`git ls-files` 显示它**已被跟踪**（含 Paper/PaperQuestion 导入，缺失会导致启动失败）。
- **影响**：当前无害，但属"定时炸弹"——任何 `git rm --cached` 或误提交 `.gitignore` 全覆盖都会让该关键文件丢失，新克隆启动即崩。
- **修复**：删除 `.gitignore` 中 `app/models/__init__.py` 这一行（它本应被跟踪）。

### P2-3 测试本地可跑性
- **证据**：`tests/conftest.py` 强制连 MySQL 测试库；当前沙箱/无 MySQL 环境无法 `pytest`。
- **影响**：开发者无本地 DB 时跑不了测试，回归靠手测。
- **修复**：仓库根加 `docker-compose.yml`（mysql:8 utf8mb4）+ 脚本 `./tools/test_up.sh`，`conftest` 读 `DB_*` 即可一键起测；或 CI 中加 MySQL service。

### P2-4 前端复用
- **证据**：`web/` 与 `admin/` 为两个独立 Vue 工程，各自维护样式/请求封装/类型。
- **影响**：重复逻辑（请求拦截、错误提示、UI 组件），双端同步成本高。
- **修复（渐进）**：抽取 `shared/` 包（axios 实例、错误码映射、通用组件、TS 类型），`web`/`admin` 以 workspace 依赖引用；不强制重写，先搬共用部分。

### P2-5 文档与代码同步
- **证据**：README 称迁移"40 个"、路由"31 个"（实际 42 / 38）；`app/config.py` 注释标 `(P2)` 等零散标记。
- **影响**：文档失真降低可信度。
- **修复**：将模块计数改为动态或定期人工核对；文档更新纳入 PR 检查清单。

## 架构层"脑暴"优化（可行、建议排期）

以下不解决"混乱"，但能**降本增效**，均基于现有结构，无推倒重来：

| 方向 | 现状痛点 | 可行方案 | 收益 |
|---|---|---|---|
| **AI 成本缓存** | 同质提问重复调大模型（"十万个为什么"已缓存，但周报/讲解未） | 对 `ai.py` 增加按 `(prompt_hash, model)` 的短 TTL 缓存（内存/LRU 或 Redis） | 直接降 token 消耗与延迟 |
| **重操作异步化** | 大试卷生成、Word 导出、邮件发送在请求内同步跑，易超时 | 引入轻量后台：`fastapi.BackgroundTasks`（小）或 Redis + Worker（大）；先对 `docx_service` 导出入队 | 请求更快、超时归零 |
| **可观测性** | 当前仅基础 `logging`，无耗时/错误率 | 加中间件记录每个 `/api/*` 耗时与状态码；关键路径结构化日志 | 线上问题秒级定位 |
| **配置中心化** | 系统配置散在 `sysconfig` KV + `.env` | 明确分层：`.env`=部署机密，`sysconfig` 表=运营可改项（已有），补管理后台配置编辑 UI | 运营自助、少发版 |
| **API 契约** | 前后端靠口头约定 | 由 Pydantic `schemas/` 自动生成 OpenAPI（开发态 `ENABLE_DOCS=true` 已支持），前端按 `/openapi.json` 生成类型 | 对接更稳 |
