# 智学学堂 · 迭代任务卡（Sprint 任务卡）

> 本文档将 `06-PRD产品需求文档.md` 与 `07-技术实施方案.md` 拆解为**可直接上板执行的迭代任务卡**。
> 每张卡片是一个独立、可验收、可排期的交付单元，供需求评审与开发对接使用。
> 编制日期：2026-09-03 · 版本 v1.0 · 配套文档 `00-总纲.md` / `01-产品优化方案.md` / `06-PRD` / `07-技术实施`

---

## 0. 使用说明

### 0.1 卡片结构

每张卡片包含：

| 字段 | 说明 |
|---|---|
| 卡片编号 | `S{n}`（M0 筑基迭代）/ `M1-S{n}`（M1 闭环迭代） |
| 周期 | 建议周次（基于 §8 里程碑，可微调） |
| 目标 | 一句话交付目标 |
| 关联需求 | 对应 PRD 的 M0-/M1- 编号 |
| 依赖卡 | 必须先完成的前置卡片 |
| 交付物 | 后端 / 前端 / 配置 / 迁移 的具体产物 |
| 任务清单 | 可勾选的具体开发项（对应 §10 Action Item 与接口清单） |
| 验收标准 | 引用 PRD 的 AC 编号 + 本卡 DoD |
| 工作量 | 后端 / 前端 / QA 人日（取自 §8.1/§8.2） |
| 负责 | 域 / 角色 |

### 0.2 状态字段

| 状态 | 标记 |
|---|---|
| 待排期 | 🔲 |
| 进行中 | 🟡 |
| 已完成 | ✅ |
| 阻塞 | ⛔ |

### 0.3 卡片与文档的追溯关系

```
06-PRD 需求域  ──┐
07-技术方案    ──┼──► 本文档「迭代任务卡」──► Sprint 看板 ──► 开发对接
08-任务卡索引  ──┘
```

> **铁律（沿用 06 §10）**：口头需求不排期；任何进入迭代的需求必须有 PRD 的 FR 编号，任何开发项必须能映射到本文档某张卡片的任务清单。
