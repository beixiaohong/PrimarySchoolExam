## 一、概览

智学学堂是面向小学（含初中）家庭的智能学习平台：孩子自主刷题/背诵、家长远程管控、游戏化激励，
并内置 AI 讲解/周报/趣味出题（钻石计费）。

- **形态**：FastAPI 单仓，同源托管两套前端（`web/` 学生端 SPA、`admin/` 管理后台）。
- **数据**：MySQL 8（utf8mb4，MySQL-only，无 SQLite），SQLAlchemy 2.0 ORM + 自建迁移系统（56 个版本脚本）。
- **规模**：后端 256 个 Python 文件 / 约 3.8 万行；学生端 23 个页面；管理端 10 个页面；测试 124 个用例。
- **健康度**：可启动、路由无冲突、无硬编码密钥泄漏。主要「软债务」是少数超大文件（`im.py` / `ledger.py` /
  `appOptions.js`），不影响运行，治理方案见 `docs/优化建议书.md`。

## 二、技术栈

| 层 | 技术 | 说明 |
|---|---|---|
| 后端 | FastAPI + Uvicorn | Python 3.12+，45 个路由前缀 / 377 个端点，统一 `require_self` 登录 + 账号绑定依赖 |
| 数据库 | MySQL 8（utf8mb4） | SQLAlchemy 2.0；迁移 `app/migrations/versions/` 按编号顺序执行（001–025 为 MySQL 基线预置「已执行」，026+ 幂等真实执行） |
| 鉴权 | DB 会话 Token | `secrets.token_urlsafe(32)` 存 `User.token`，非 JWT；`require_self` 强制 `user_id == 登录账号` |
| 学生端 | Vue 3 + Vite（`web/`） | SPA，构建到 `web/dist`，由后端 `/` 托管 |
| 管理端 | Vue 3 + Vite（`admin/`） | Hash 路由（`/admin#/...`），构建到 `admin/dist`，由后端 `/admin` 托管 |
| AI | 智谱 GLM / Relay 中转 / DeepSeek | 单入口 `app/services/ai.py`，免费链兜底 + VIP 追加付费链，按 token 扣钻石 |
| 媒体 | python-docx / matplotlib / edge-tts / PyMuPDF | 试卷 Word、数学图形、TTS 音频、PDF 渲染 |
| 测试 | pytest + FastAPI TestClient | 20 个文件 / 124 用例，独立 `_test` 库隔离，AI/邮件全打桩 |

### 4.5 `app/migrations/`
- `runner.py`：按编号顺序执行未应用版本，状态记 `schema_migrations` 表。
- `versions/`：**56 个**脚本。001–025 为历史 SQLite 方言（MySQL 下预置「已执行」，由 `create_all` 建表），
  026+ 为幂等真实执行（建表 / 加列 / 种子）。
- 近期：047 教材版本 → 048 网课 → 049 用户启用标记 → 050 知识点 → 051 任务确认状态统一 → 052 家长自定义任务补列。
