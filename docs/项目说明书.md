## 一、概览

智学学堂是面向小学（含初中）家庭的智能学习平台：孩子自主刷题/背诵、家长远程管控、游戏化激励，并内置 AI 讲解/周报/趣味出题（钻石计费）。

- **形态**：FastAPI 单仓，同源托管两套前端（`web/` 学生端 SPA、`admin/` 管理后台）。
- **数据**：MySQL 8（utf8mb4），SQLAlchemy 2.0 ORM + 自建迁移系统（42 个版本脚本）。
- **健康度（本次审计结论）**：可启动、路由无冲突、无硬编码密钥泄漏、无启动即崩风险。主要"软债务"是少数超大路由文件与少量死代码，不影响运行。

## 二、技术栈

| 层 | 技术 | 说明 |
|---|---|---|
| 后端 | FastAPI + Uvicorn | Python 3.12，38 个路由模块，统一 `require_self` 登录+账号绑定依赖 |
| 数据库 | MySQL 8（utf8mb4） | SQLAlchemy 2.0；迁移 `app/migrations/versions/`（编号顺序执行，001–025 为 MySQL 基线预置"已执行"） |
| 鉴权 | DB 会话 Token | `secrets.token_urlsafe(32)` 存 `User.token`，非 JWT；`require_self` 强制 `user_id==登录账号` |
| 学生端 | Vue 3 + Vite（`web/`） | SPA，构建到 `web/dist`，由后端 `/` 托管 |
| 管理端 | Vue 3 + Vite（`admin/`） | Hash 路由（`/admin#/...`），构建到 `admin/dist`，由后端 `/admin` 托管 |
| AI | 智谱 GLM / Relay 中转 / DeepSeek | 单入口 `app/services/ai.py`，免费链兜底 + VIP 追加付费链，按 token 扣钻石 |
| 媒体 | python-docx / matplotlib / edge-tts / PyMuPDF | 试卷 Word、数学图形、TTS 音频、PDF 渲染 |
| 测试 | pytest + FastAPI TestClient | 14 个文件、58 用例，独立 `_test` 库隔离，AI/邮件全打桩 |
