## pytest 32 个失败用例 → 115/115 全绿（Task #203 完成）
### 根因一：conftest 的 AuthClient._merge 注入 token 有 bug（约占 23 个失败）
- 旧逻辑：`if "headers" in kwargs: return kwargs` —— 只要测试传了额外 headers（如家长写接口的 `X-Parent-Pwd`），就**跳过 Bearer token 注入** → 家长写接口全部 401（而非预期的 403/200）。
- 修法：合并 token 进现有 headers（除非已显式带 `Authorization`）；user_id 从 body/query/URL 提取，缺省回退 `test_auth_uid`。

### 根因二：Python 早绑定（semester early-binding）导致 monkeypatch 无效
- `from app.services.semester import current_semester` 在 import 时绑定函数，monkeypatch 对调用点无效。
- 修法：改成 `from app.services import semester as _semester` 再 `_semester.current_semester()`。
- 涉及：`app/routers/vocab/common.py`、`app/routers/classical/recite.py`、`app/services/sync_service.py`。
