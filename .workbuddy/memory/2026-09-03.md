## 🔴 S2-M2 排查出的关键坑（对 M3/M4 及所有 DB/测试极重要，务必牢记）
1. **`SessionLocal(autoflush=False)`**（`app/database.py` L24）：写后同会话内 `query` 看不到 pending 行，必须显式 `db.flush()`/`commit()`。服务内「先写后读」的测试须 flush；批量服务里的批内去重不能依赖 autoflush 看到 pending 行 → 用 in-memory `seen` 集合（已在 `batch_import` 落地）。

3. **`get_annotation_queue` 将 `page_size` 封顶 `MAX_PAGE_SIZE=100`**：分页遍历测试必须用 `page_size=100` 且按 `len(items) < 100` 判定末页，不能用大 page_size（会被静默截断到 100）。
4. **session 级共享测试库串扰**：其它用例可能残留 `QuestionKpMap`（FK 清理顺序/隔离不足）。标注类测试须「防御性 `delete` 本测试题的 kp_map + 用增量断言（`annotated` 前后差 1）」而非绝对值 `==0`，否则全量回归随机失败。
