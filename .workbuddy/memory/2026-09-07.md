### 🔴 关键调研发现（决定方案可行性）
1. **web 端零上传/录音能力**：全仓 `web/src` 无 FormData/upload/MediaRecorder/getUserMedia
   → 图片与语音都要从零实现。
2. **🚨 后端上传白名单无音频**：`app/domains/frozen/routers/im.py:1206` 的
   `ALLOWED_MIME_TYPES` 只有 image/jpeg|png|gif|webp + pdf/txt/office，**无 audio/** *。
   → 语音消息**必须**先补 MIME（B1），否则上传必被 400 拒。这是方案里唯一 P0 后端改动。
3. **web 无图表库**：`web/package.json` 仅 vue/vue-router/pinia/html2canvas。
   `StatsView.vue` 用 `.progress` + `width:%` 纯 CSS 画进度条 → 账本分析图表手写 SVG+CSS，不引依赖。
4. **前端架构**：`App.vue` 壳 `provide(){return {appCtx:this}}`，各 View `inject:['appCtx']`
   零业务 data；视图 `<xxx-view v-if="tab==='xxx'">` 切换；全局注册在 `main.js`；导航在 `nav.js`。
   业务逻辑放 `web/src/logic/*.js`（mixin 展开，如 appOptions.js / parent.js）。
5. **鉴权**：`web/src/api/http.js` 的 `api()` 自动带 `Bearer localStorage.zx_token`；
   WS 走 `?token=`（同一 token）。账本接口需传 `user_id`（取 appCtx.user），IM 靠 token 解析。
6. **IM 上传接口**：`POST /api/im/upload/file`（FormData，≤10MB），返回 `file_url/file_name/file_size`，
   存储 `output/im_uploads/`，URL 前缀 `/output/im_uploads/`。

### 🔴 本次调研挖到的硬约束（务必记住）
1. **`POST /recurring/run-due`（ledger.py:925）依赖 `current_user`，只处理登录者本人的到期交易**，
   调度器无法直接调 → 必须新增全量扫描服务函数，不能只挂个 HTTP 调用。
2. **红包 claim 全程无行锁**（读→判→减→写），改真资产后是**资损风险** → B11 必做（with_for_update
   或条件更新按影响行数判定）。
3. **单位冲突**：红包 `total_amount` 是 Integer（原"积分"），钻石 `diamond_accounts.balance` 是
   **Float（2 位小数）**。方案定 **1 钻石 = 1000 毫钻**，整型存储避免拼手气拆分浮点缺口。
4. **frozen → commerce 跨域合法**：import-linter 白名单 `app.domains.** -> app.domains.*.contracts`
   允许 frozen 引 `commerce.contracts`（`DiamondService.charge/grant`），**禁止直连 `services/diamond.py`**。
5. **requirements.txt 无音频库、全仓无敏感词模块** → ffmpeg 需服务器 `apt install`，词库从零建。
6. **持连铁律**：ffmpeg 是外部阻塞调用，上传接口必须「分段短会话」，不得在 get_db 会话内转码。

其他：后端改动清单由 B1–B7 扩为 **B1–B16**；实施计划调整为 **P1–P7**（新增 P5 红包钻石、P6 后台含敏感词）；
