## 高项知识点展现形式优化（提交 7421071，已推送）

用户诉求：「优化高项知识点展现形式」。

**现状问题**：弹层正文是「按行拆段 → 纯 `<p>` 平铺」，PDF/AI 抽取原文里的
「第1章」「一、」「1.」「（1）」与填空的「（）」全糊成一大坨，长清单尤其难读。

**做法**：正文改为结构化块，解析与拼装收敛成纯函数（可 node 直测）：
- `logic/gaoxiang.js::gxKParseBlocks`（结构）/ `gxKBlocksHtml`（HTML）
  · 小标题：`第X章/节`、中文序号「一、」（≤30 字且不含句号）、多级编号（`1.2`/`2.3.1`）
  · 条目：`1.`/`1、`/`（1）`/`•`/`-`；连续条目归组，**按序号形态分组**（数字组 / 括号组分开）
  · 空括号「（）」→ 填空空框；括号内有内容（`（如 GB/T）`/答案区 `（立项）`）保持原文
  · 一律先 HTML 转义再拼装（v-html 双保险）；判定保守（长行宁可当段落）
- computed：`gxKAskParas`/`gxKAnswerParas` → `gxKAskHtml`/`gxKAnswerHtml`（不留两份判定）
- `GaoxiangView.vue`：弹层与答案区改 `v-html`，新增 `.gx-k-h/.gx-k-ul/.gx-k-li/.gx-k-li-no/.gx-k-blank`

**🚨 本轮踩到并固化的坑**：**scoped 样式不作用于 v-html 产出的 DOM**。
构建后规则变成 `.gx-kcontent .gx-k-blank[data-v-x]`，而 v-html 节点没有 `data-v`
→ 一条都不匹配（正文会挤成一坨、空框不显示），**而 SFC 编译、vite build、
测试全部报绿**，只能靠看产物选择器发现。修法：所有后代选择器 `:deep()` 穿透
（编译为 `.gx-kcontent[data-v-x] p`），已写进主记忆「关键坑」。

**验证**：解析断言 14 项全过（标题/多级编号/三种条目分组/空括号→空框/
括号有内容保持文本/段落不误判/HTML 注入被转义）；`verify_vue_sfc` 错误 0；
`web` 构建成功（16.9s）并核对产物含全部新类名与 `:deep` 编译结果；
`regression_check` 7 项全过。

**验收辅助**：`temp/_gen_gx_preview.mjs`（临时、不入库）用真实解析输出 +
从 SFC 提取的样式（`:deep` 已还原）生成「改版前 vs 改版后」对照页，
已 present 给用户看效果。

**下一步（待用户定）**：① 部署后真机验收；② 是否给设置页「极速模式」与家长侧
学习配置的开关也统一成新样式（上一轮的样式统一遗留）；③ 若要做「已读标记」，

## 开关显示统一（承接上一条的用户反馈，2026-09-29）

用户回复「继续任务」→ 落在上一轮遗留项②：**其余 4 处开关仍是旧写法**。

**问题**：上一轮只修好了推送开关（文字 + 色点 + 真实开关），而
设置页「极速模式」与家长端 `ParentStudyConfig` 的 3 个 `studyFlags` 开关
仍是「按钮上写状态词」的旧样式 —— 同一判定并存两套实现，且旧写法正是用户
抱怨「不知道当前是开的还是关的」的形态。

**做法：抽唯一实现，而不是再抄一份样式**
- 新增 **`web/src/components/StateSwitch.vue`**（全局注册 `<state-switch>`，
  与 `AppIcon` 同一处）：props `on/label/tone(ok|warn|danger|off)/disabled/busy/title`，
  事件 `@toggle`。状态 = 文字 + 颜色，动作 = 开关位置；左侧已写明状态时 `label` 留空。
  · 保留「用 `role="switch"` 的 button 而非 `<input type="checkbox">`」的理由注释
    （checkbox 的 `:checked` 是属性绑定，状态未变时不重渲染 → 回滚会留「界面开着数据是关的」）。
- 接入 4 处：设置页「极速模式」、家长端 预习下学期 / 课堂同步 / 小升初衔接。
- **顺手把推送开关也换成该组件**（本设备行 + 逐场景行）：否则 `.push-switch`
  与 `.ss-sw` 会同居两份；设置页里 `.push-ctrl/.push-state/.push-switch` 样式已删除，
  仅保留 `.push-pill/.push-dot/.push-row*/.push-hint/.push-alert/.push-time`。

**验证**

  与 `ParentStudyConfig.vue`**（此前会「0 错误」但根本没校验到新文件）。
- `web` 构建 17.2s 成功；产物核对：`.ss-sw[data-v-3be65d93]` 等规则齐全，
  且作用域属性挂在**主体**选择器上（没有重蹈上一轮 v-html 的 `:deep` 覆辙）；
  `push-switch` 在产物 CSS 里出现 0 次（旧样式确实清除）。
